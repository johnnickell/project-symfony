# Local adoption of PRD-00018

This repository owns the Symfony-relevant product, walking-slice, architecture, documentation, and build
acceptance authority.

The adoption is a provenance record, not a competing umbrella status board. Future detailed tickets and status
live here. Fight Common retains only the repository dependency and handoff receipt.

## Local interpretation

Symfony owns native service loading, autoconfiguration, compiler-pass registration, aliases, environment
configuration, HTTP/security composition, and future persistence and presentation adapters. Shared behavior is
consumed through public Composer packages only. There is no Fight bundle and no copied Fight Common or Fight
AccessControl Domain/Application source.

Bootstrap establishes only the governed foundation. Its verification is the repository-local noninteractive build,
the hosted build, and a clean-clone receipt bound to an immutable commit. Login extraction, persistence, browser
journeys, release actions, and any public transition beyond source visibility require separate local tickets and
approvals.
