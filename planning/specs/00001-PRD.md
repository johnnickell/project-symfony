# Framework Starter Product and Walking-Slice Acceptance

## Local authority

This repository owns the Symfony-relevant product, walking-slice, architecture, documentation, and build
acceptance authority. PRD-00001 is this repository's durable product requirement; ticket status and execution
order remain in `planning/tickets/`.

Symfony owns native service loading, autoconfiguration, compiler-pass registration, aliases, environment
configuration, HTTP/security composition, and future persistence and presentation adapters. Shared behavior is
consumed through public Composer packages only. There is no Fight bundle and no copied Fight Common or Fight
AccessControl Domain/Application source.

## Product boundary

Bootstrap establishes a governed Symfony foundation that can consume the two Fight packages through Composer.
Login extraction, persistence, browser journeys, releases, and public-readiness claims require separately adopted
local tickets. Each later user-valued slice is repository-owned, uses framework-native adapters, and preserves the
shared package boundary.

## Acceptance boundary

The bootstrap acceptance is the repository-local noninteractive build, hosted build, clean-clone Composer
installation, architecture checks, and a clean-clone receipt bound to an immutable commit. Hosted CI delegates to
the same `./bin/build` command. Source visibility does not authorize a tag, Packagist publication, template
enablement, create-project distribution, or any feature not named in a local ticket.
