# Symfony Starter Product and Walking-Slice Acceptance

## Problem Statement

A new Symfony starter project needs governed boundaries: explicit Fight Common container definitions, routes,
middleware, handlers, HTTP, and presentation composition. Fight Common and Fight AccessControl must remain
public Composer packages only.

## Solution

The bootstrap establishes a governed hello-world foundation with Docker-backed tooling, a canonical `./bin/build`
gate, hosted CI, and public-source guidance.

## Implementation Decisions

- Repository-local planning, architecture, triage, and public-source guidance are canonical.
- Docker-backed Composer, PHPUnit, lifecycle, and build wrappers exist.
- `./bin/build` is the single noninteractive local and hosted gate.
- MIT, contribution, and security policies are present.

## Testing Decisions

- `./bin/build` validates the public Composer boundary and the Fight Common container-backed hello-world seam.
- Hosted CI invokes the exact same `./bin/build` command, providing a hosted build receipt.

## Out of Scope

- Login, persistence, browser journeys, releases, tags, Packagist publication, template enablement, create-project distribution.
