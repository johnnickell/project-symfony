# Run One Reusable Local and Hosted Gate with Durable Unit Coverage

## Outcome

Make `./bin/build` one reusable local/hosted gate in the prepared running Compose `api` service, with named,
fail-fast PHP phases and durable, independently attributable Unit coverage. This completes the gate migration
specified by [T-00010](../tickets/00010-TICKET.md) under [EPIC-00001](../epics/00001-EPIC.md), building on
[TASK-00005](00005-TASK.md). Follow [planning conventions](../CONVENTIONS.md).

## Scope

- In scope: the thin build wrapper, PHP phase orchestration, coverage-report configuration/checker and focused
  wrappers as needed, explicit hosted preparation, and affected README/engineering verification guidance.
- Retain host-side Python planning validation for normal and linked worktrees. Do not mount/share unsafe Git
  metadata, duplicate planning validation in PHP, or add Python quality-gate orchestration.
- Preserve planning validation, strict Composer validation and platform checks, PHP syntax, installed FightCommon
  PHPCS, PHPStan, both Deptrac checks, Rector dry-run, exact Unit coverage and all retained suites/failure flags.
- Preserve the `src/` coverage denominator excluding only the Kernel, direct coverage metadata, production
  ignore-directive rejection, report validity/contradiction checks and exact covered/total statement equality.
- Supersede only T-00007's per-build image/dependency preparation mechanics and the shared coverage-artifact
  overwrite behavior. Do not rewrite historical completion evidence or retire stronger verification requirements.
- Out of scope: dependency upgrades, test reclassification/removal, new application behavior/services, full WF-002
  topology, browser suites, tooling self-tests, invalid fixtures, certification lanes, release and deployment.
  This TASK does not itself grant publication authority.
